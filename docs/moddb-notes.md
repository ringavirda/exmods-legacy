# Mod database listing notes

The prepared releases are ppex 0.7.1 and smex 0.10.1, both on exlib 0.8.4 or later; the owner
uploads them through the web form once exlib 0.8.4 is out, and nothing here is published
automatically. The mod database takes the 1.22 zips. The 1.21 and 1.20 zips of ppex and smex go on
this repository's GitHub releases page; exlib's own release carries its zips for every game
version.

The listing descriptions are `docs/ppex/moddb.html` and `docs/smex/moddb.html`; exlib's is
exdocs `exlib/moddb.html`. Each one shows what is in the mod and links the exwiki page that explains
it, so the mechanics and their numbers live on the wiki and not on the listing. A listing
description can be edited without a release.
